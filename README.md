# MISTVALE · 미스트베일

게임 타이틀에서 빙의 후 첫 선택지까지 이어지는 인터랙티브 판타지 농장 세계의 1차 오프닝입니다. 현재 버전은 UI·로딩 개선판 v0.2입니다. 순수 HTML / CSS / JavaScript로 구성했으며 빌드나 런타임 의존성이 없습니다.

## 실행

Node.js 20 이상에서 저장소 루트의 `npm run serve`를 실행하고 `http://127.0.0.1:4173/mistvale/`를 엽니다. 별도 패키지 설치는 필요 없습니다. Python이 있다면 `python -m http.server 8000` 실행 후 `http://localhost:8000/`에서도 볼 수 있습니다. ES 모듈을 사용하므로 파일을 더블클릭하는 `file://` 방식 대신 HTTP 서버를 사용해 주세요.

## GitHub Pages 배포

1. 검토용 PR을 `main`에 병합합니다.
2. 저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
3. **main / (root)**를 선택하고 저장합니다.
4. Pages 배포 작업이 성공하면 `https://x-x77.github.io/mistvale/`에서 확인합니다.

모든 프로젝트 파일 경로는 상대 경로입니다. 해시 라우팅을 사용하므로 `/mistvale/#choices` 같은 URL에서 새로고침해도 서버 경로 오류가 발생하지 않습니다. `.nojekyll`을 포함했습니다. 위 주소는 배포 후 사용할 주소이며, PR 제출만으로 배포가 완료되지는 않습니다.

## 구현 내용

- 세이지·크림 톤의 픽셀 농장 타이틀, 움직이는 빛과 입자, NEW GAME / CONTINUE / SETTINGS.
- 중성적인 익명 농장주의 도트 농사 애니메이션(걷기 → 씨앗 → 물주기 → 새싹). 이미지 준비와 최소 연출 시간이 결합된 진행바, 숫자 없는 로딩, 빙의 직전의 짧은 이상 징후.
- 중심에서 퍼지는 빛, UI 흐림과 소멸, 백색 유지, 일러스트 농가가 선명해지는 전환.
- 연출 건너뛰기와 장면별 AbortController를 통한 이전 타이머 취소.
- 감각 중심의 내레이션 6개와 베르의 대사 3개. 기본 자동 진행, AUTO ON/OFF, SKIP. 문장 출력 완료 후 글 길이·출력 속도에 따른 3.2~11초 읽기 시간을 확보합니다. 클릭/Enter로 즉시 완성 또는 다음 문장, 설정창과 숨긴 탭에서는 자동 진행 일시정지, 선택지에서는 자동 진행 종료.
- 다크그린 RPG 등록창, 구획화된 농장주 정보, 세 선택지의 호버·선택 피드백. Tab / 위아래 화살표 / Home / End / Enter 선택, 농가·마을 소개와 로그아웃 오류 후 베르의 반응.
- 설정 모달과 ESC 닫기, 기본 OFF 효과음, 출력 속도, 동작 줄이기 및 시스템 설정 존중.
- 설정과 오프닝 완료 상태를 localStorage에 보관. 저장이 차단되면 메모리 상태로 진행하고 안내 표시.
- 오프닝 완료 후 CONTINUE는 농가에서 눈뜨는 장면부터 재개. 개별 대사 위치는 저장하지 않습니다.
- 새로고침과 브라우저 뒤로/앞으로 가기. 로딩 중 새로고침은 안전하게 타이틀로 복귀.
- 이미지 실패 시 대체 배경 및 베르 텍스트 표시. Google Fonts 실패 시 로컬 폰트 사용.

## 에셋과 확장 범위

세 이미지는 이번 오프닝을 위해 AI로 생성한 콘셉트 에셋입니다. 빈 자리 표시 이미지는 아니지만 최종 아트 디렉션 승인을 받은 외주 일러스트로 표현하지 않습니다. 같은 파일명으로 교체하거나 `styles.css`와 `js/data.js`의 경로를 함께 변경할 수 있습니다. 배경 두 장과 베르가 서로 독립적입니다.

농가·마을 선택지의 결과는 의도적으로 짧은 임시 소개 화면입니다. 월드맵, 주민 도감, 상점, 미니게임, 계정, 데이터베이스는 구현하지 않았습니다. 배경음악은 없으며 효과음은 합성된 짧은 차임입니다.

## 테스트

`npm test`로 저장 회귀 테스트를 실행할 수 있습니다. 브라우저 수동 점검 기록과 제한 사항은 [TESTING.md](./TESTING.md)를 참고하세요.

## 로딩 에셋 교체

현재 도트 농장주와 달리는 도트 베르는 코드로 그린 임시 애니메이션입니다. 기존 `assets/title.jpg`, `assets/room.jpg`, `assets/ver.png`는 변경하지 않았습니다. 스프라이트 시트 교체 및 이동 로딩 사용법은 [로딩 가이드](./assets/LOADING.md)를 참고하세요. 베르 일러스트의 배치는 `ui.css`의 `--ver-width`, `--ver-right`, `--ver-bottom`으로 조절합니다.
