- 390×844: 17곳/23명 이미지 및 배경 로딩, 3개 첫 대사, 완료 후 재방문 인사, 닫기 및 지도 복귀 모두 통과.

- 원화 경로: serepina→seraphina, kylen→kailen, nepia→nephia 별칭도 확인.
- 실물 휴대폰 테스트는 하지 않았습니다. 이미지 품질 검수는 원본/결과 비교와 브라우저 크기의 육안 검사입니다.

## 생성 기록
모드: 내장 imagegen, 배경 제거는 transparent_background:true. 투명 PNG를 그대로 복사, 새 장소 배경은 크기 변경 없이 JPEG 품질88로 저장했습니다.

추가 회귀 확인: 스토어 갤러리 → 타이틀 → 새 게임 → 로딩 → 농가 각성 → 베르 대사 → 초기 선택지 3개 표시를 확인했습니다. 음악 켜기 UI와 설정에서 속도/모션 감소 변경을 확인했습니다. 실제 스피커 청음 검증은 하지 않았습니다.
생성 프롬프트와 파일별 원본 경로: unified-scenes-generation.json. 최종 에셋: assets/characters/cutouts/*.png, assets/world/scene-*.jpg.

초기 선택지의 마을 진입으로 dev 우회 없는 지도 이동도 통과했습니다. 테스트 후 음악/모션 감소/출력 속도를 기존 값으로 복구했습니다.
